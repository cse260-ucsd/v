CUTLASS, step by step · Introduction

Terms, scale and shorthand

Parts 1 and 2 build a matrix multiply, C = A · B, on a GPU shrunk to fit on screen. This page defines the words they use, lists where the small model differs from an NVIDIA Tesla T4, and translates the pseudo-code into CUDA C++.

Terms

Who does the work

Kernel
A function that runs on the GPU. One launch runs it once in every thread, all with the same code. Threads differ only in their index variables.
Thread
One run of the kernel, with its own registers. In this series, one thread computes one number of C.
Warp
32 threads with consecutive IDs in a block (4 in this series). The hardware issues one instruction for the whole warp at a time, and it sends the warp's memory requests to memory together.
Blockthread block · CTA
A group of threads that runs on one SM. Its threads share that block's shared memory and can wait for each other at a barrier. Threads in different blocks can do neither. CUTLASS calls a block a CTA (cooperative thread array).
Grid
All the blocks of one kernel launch.
SMstreaming multiprocessor
One of the processors on the GPU chip. It runs the threads of the blocks assigned to it and holds their registers and shared memory. A Tesla T4 has 40 SMs.
threadIdx, blockIdx
A thread's position in its block, and its block's position in the grid. Each has .x, .y and .z.
blockDim, gridDim
The size of a block in threads, and of the grid in blocks, as set at launch.

Where data lives

Global memory
The GPU's main memory (16 GB on a T4). Every thread can read and write it, but each trip takes hundreds of cycles. A, B and C live here.
Shared memory
Small, fast memory on each SM. Each block gets its own piece, which all of its threads can read and write. Part 2's As and Bs live here.
Registers
The fastest storage, private to one thread. Ordinary local variables such as acc live here.

Ideas the parts build on

Row-major
A matrix stored row by row, so A[row][k] sits at address A + row · N + k. Numbers next to each other in a row are neighbors in memory.
Coalesced load
When a warp's threads read neighboring addresses, the GPU serves them with a few wide memory transactions instead of one per thread. Part 1.
Tile
A small square piece of a matrix that a block copies into shared memory and works on before moving to the next. Part 2.
Barrier
A point in the kernel where every thread of a block waits until all of them have reached it. Part 2's sync().

Part 1's kernel in CUDA C++

__global__ void matmul(const float *A, const float *B, float *C, int N)
{
    int row = blockIdx.y * blockDim.y + threadIdx.y;
    int col = blockIdx.x * blockDim.x + threadIdx.x;   // threadIdx.x along a row: coalesced

    float acc = 0.0f;
    for (int k = 0; k < N; k++)
        acc += A[row * N + k] * B[k * N + col];
    C[row * N + col] = acc;
}

dim3 block(4, 4);
dim3 grid(N / 4, N / 4);
matmul<<<grid, block>>>(A, B, C, N);

Part 2's kernel in CUDA C++

constexpr int TILE = 4;

__global__ void matmul_tiled(const float *A, const float *B, float *C, int N)
{
    __shared__ float As[TILE][TILE], Bs[TILE][TILE];
    int tx = threadIdx.x, ty = threadIdx.y;
    int row = blockIdx.y * TILE + ty;
    int col = blockIdx.x * TILE + tx;

    float acc = 0.0f;
    for (int t = 0; t < N / TILE; t++) {
        As[ty][tx] = A[row * N + t * TILE + tx];
        Bs[ty][tx] = B[(t * TILE + ty) * N + col];
        __syncthreads();
        for (int k = 0; k < TILE; k++)
            acc += As[ty][k] * Bs[k][tx];
        __syncthreads();
    }
    C[row * N + col] = acc;
}

// N must be a multiple of TILE
dim3 block(TILE, TILE);
dim3 grid(N / TILE, N / TILE);
matmul_tiled<<<grid, block>>>(A, B, C, N);
